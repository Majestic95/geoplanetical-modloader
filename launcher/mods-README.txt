MODS FOLDER
===========

Put each mod in its own folder here, as it came in the mod's download. A mod folder holds a mod.json file
and a patches folder, for example:

  mods\
    some-mod\
      mod.json
      patches\
        ...

Then open (or reopen) GeoplaneticalModLoader.exe: the mod appears in its list with a switch.

- Do not put two versions of the same mod here. Delete the old folder before adding the new one.
- A mod made for another version of the game is listed but cannot be switched on until its author updates it.
- A mod that needs another mod says so in the list; switch both on.
- Mods are data files only. The loader checks every change a mod makes before the game starts, and
  never changes the game's own files.
